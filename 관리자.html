페이지 꾸미기

아래 버튼을 누르면 사진과 문구를 편집하는 Pages CMS가 새 창으로 열립니다.

사진·문구 수정하러 가기 ↗

처음에는 GitHub 계정으로 로그인해 주세요. 연결 설정이 끝난 사이트부터 편집할 수 있습니다.

Pages CMS에서 이 웹사이트의 저장소를 선택해 주세요.

  1. 내 사이트 선택Pages CMS에 로그인하고 이 사이트를 선택하세요.
  2. ‘다운로드 페이지 꾸미기’ 열기사진, 안내 문구, 버튼 글자와 스마트스토어 주소를 바꾸세요.
  3. Save / 저장 누르기저장하면 웹사이트에 반영되기 시작합니다. 반영이 끝날 때까지 잠시 기다려주세요.

사진 다운로드 주소는 고객의 QR코드에서 자동으로 가져옵니다.

처음 한 번 연결이 필요해요

사이트를 준비하는 사람이 GitHub 저장소와 Pages CMS를 한 번 연결해야 합니다. 연결이 끝난 후에는 관리자가 위 버튼으로 편집하면 됩니다.

사이트가 목록에 안 보여요

Pages CMS에서 올바른 GitHub 계정으로 로그인했는지 확인하세요. 사이트를 준비한 사람에게 해당 저장소를 Pages CMS에 연결해 달라고 요청하세요.

저장했는데 화면이 그대로예요

GitHub Pages가 새 내용을 게시하는 데 시간이 걸릴 수 있습니다. 잠시 후 ‘게시한 내용 다시 확인’을 눌러주세요. 계속 바뀌지 않으면 사이트를 준비한 사람에게 배포 상태를 확인해 달라고 요청하세요.

예약 버튼이 작동하지 않아요

‘스마트스토어 예약 주소’에 https://로 시작하는 실제 주소를 넣고 저장하세요. 주소를 비워두면 고객에게 준비 중 안내가 표시됩니다.
